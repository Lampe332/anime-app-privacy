# Anime App – Privacy Policy / Datenschutzerklärung

Privacy policy for the Android app **Anime App**, in English and German.

**Read it here: https://lampe332.github.io/anime-app-privacy/**

## What is in this repository

- `index.html` – the policy as a single, self-contained page (own CSS, no external fonts, scripts or trackers). It has an EN/DE switch, follows the device's light/dark mode and is made for phone screens.
- `README.md` – this file.

## Short version

- No accounts and no servers of our own, no ads, no analytics, no tracking.
- App data stays on the device.
- The app connects only to AniList, the episode metadata services, a public announcements file and the marketplace or extension addresses the user enters, plus Google Play Age Signals for the age check.

## Contact

Open an [issue](https://github.com/Lampe332/anime-app-privacy/issues). Please do not post personal data there.
